# C# Calculator (Windows Forms)

Midterm seatwork: a basic calculator desktop app built with C# and Windows Forms.

## Features

- Number buttons 0–9 and decimal point
- Add, subtract, multiply and divide
- **Del** to remove the last digit, **AC** to clear everything
- Shows a message if you press = without a number

## Tech

C# · .NET Framework · Windows Forms

## Run It

Open `AlonsoMidtermSeatwork/AlonsoMidtermSeatwork.sln` in **Visual Studio** and press **F5**.
